# FNF Audio → FLM Converter

Experimental **direct audio → FL Studio Mobile (.flm)** converter. MIDI is deliberately not used, because it loses FL Studio-specific semantics such as slide notes and makes the training/reference target less faithful.

## v0.1 scope

This first calibration build targets **isolated monophonic FNF character vocals**. It detects F0, segments sung/sample notes, distinguishes continuous pitch transitions from ordinary note changes, and writes normal + slide events directly into the FLM `EVN2` stream.

The FLM writer is derived from the existing `Vitkkk/Flp-converter-` project and its real FL Studio Mobile 4.10.17 DirectWave template. FLM note timing uses 128 units/beat and EVN2 v20.

## Install

```bash
python -m pip install -e .
```

## Convert

The exact project BPM is required in v0.1:

```bash
audio2flm vocals.wav --bpm 160 -o vocals_generated.flm --debug-json vocals_generated.json
```

Supported input depends on libsndfile/FFmpeg available on the machine; WAV and FLAC are the safest choices.

## Why `--debug-json` matters

Keep the JSON when testing. For the next calibration pass, provide:

1. the isolated vocal audio used as input;
2. the FLM generated by this converter;
3. the original hand-authored/correct FLM;
4. the debug JSON;
5. the exact BPM.

The comparator planned for v0.2 will match original vs generated EVN2 events and report pitch, onset, duration and slide-specific errors. That allows tuning against real FLM ground truth rather than MIDI.

## Current limitations

- Monophonic vocal only; no chords/polyphonic transcription yet.
- BPM must be supplied manually.
- Slide detection is heuristic and intentionally conservative in v0.1.
- No automatic DirectWave sample/chromatic mapping yet; the FLM contains the detected piano-roll events in the template channel.
- Fine pitch is approximate pending calibration against more real FLMs.

## Architecture

`audio -> F0/RMS analysis -> note segmentation -> slide classifier -> internal NoteEvent list -> native FLM EVN2 writer`

No MIDI stage exists anywhere in the conversion path.
